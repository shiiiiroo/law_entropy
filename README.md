# Law Entropy

Система интеллектуального анализа нормативно-правовых актов (НПА) Республики Казахстан. Проект позволяет находить юридические коллизии, устаревшие нормы и визуализировать связи между документами.

## Основные возможности

- **Поиск противоречий**: Сравнение нескольких НПА на предмет логических и юридических конфликтов.
- **Детектор устаревших норм**: Автоматический поиск ссылок на утратившие силу акты.
- **Интерактивный граф**: Визуализация иерархии и зависимостей документов с помощью D3.js.
- **AI-ассистент**: Контекстный чат по загруженным документам.
- **Мультиязычность**: Поддержка русского, казахского и английского языков.

## Быстрый запуск (Docker)

Самый простой способ запустить проект — использовать Docker Compose. Это развернет и фронтенд-прокси, и парсер-бэкенд одной командой.

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Запустите сборку:
   ```bash
   docker-compose up --build
   ```
3. Откройте приложение: [http://localhost:3000](http://localhost:3000)

## Ручной запуск (для разработки)

### 1. Фронтенд и Прокси (Node.js)
```bash
npm install
npm start
```
Сервер будет доступен на порту 3000.

### 2. Бэкенд-парсер (Python)
```bash
cd backend
python -m venv venv
source venv/bin/activate # или venv\Scripts\activate на Windows
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## Технологический стек

- **Frontend**: HTML5, Vanilla JS, D3.js (визуализация), PDF.js/Mammoth (парсинг файлов).
- **Proxy**: Node.js, Express (обход CORS, статика).
- **Backend**: Python 3.11, FastAPI, BeautifulSoup4 (web scraping).
- **AI Providers**: Google Gemini, AlemLLM, Groq, DeepSeek, OpenAI, Anthropic.
